Quicksales Inventory API Documentation

Welcome to the Quicksales Developer REST API! Use this API to query branch stock levels, product details, pricing, and availability to integrate directly with your custom platforms, e-commerce stores, or WhatsApp conversational bots.

Developer Sandbox Setup

🚀
Free Developer Access

Developers do not need to buy a business plan. You can register a free account to generate sandboxed API keys and test your integration indefinitely.

Step 1: Create a Developer Account

  1. Click Start Free Trial on the landing page.
  2. Fill out your account details.
  3. In the Business Type dropdown form field, select Developer Sandbox.
  4. Submit the form to create your sandbox dashboard.

Step 2: Generate Your API Key

  1. Log in to your sandbox dashboard and click Settings in the sidebar.
  2. Scroll down to the API Integration card.
  3. Enter a label for your key (e.g. WhatsApp Integration) and click Generate Key.
  4. Copy the generated token string immediately. It will start with qs_live_.

Authentication

Authenticate all requests by including your active token in the HTTP request headers. The API supports both custom header keys and standard Bearer Authorization headers.

Option A: Custom Header (Recommended)

X-API-Key: qs_live_your_api_token_here

Option B: Bearer Token Header

Authorization: Bearer qs_live_your_api_token_here

API Endpoints Reference

GET /api/v1/inventory/status/

Retrieves high-level summary metrics of all inventories in the organization or scoped to a specific branch.

Query Parameters:

  • branch_name (optional): Filter metrics to a branch (e.g., ?branch_name=Ugbowo).
  • branch_id (optional): Scopes directly by UUID branch ID.

Example Request:

curl -H "X-API-Key: qs_live_test_key_123456" \
     "http://localhost:8000/api/v1/inventory/status/?branch_name=HQ"

Response (200 OK):

{
  "status": "success",
  "organization": "Bobby's Place",
  "branch": "HQ",
  "metrics": {
    "total_skus": 12,
    "in_stock": 10,
    "out_of_stock": 2,
    "low_stock": 3
  }
}
GET /api/v1/inventory/products/

Returns a list of all products in stock, showing category, quantity available, and pricing.

Query Parameters:

  • search (optional): Search filter matching name or code (e.g., ?search=Mouse).
  • branch_name (optional): Scopes list to a branch (e.g., ?branch_name=HQ).

Example Request:

curl -H "X-API-Key: qs_live_test_key_123456" \
     "http://localhost:8000/api/v1/inventory/products/?search=Mouse"

Response (200 OK):

{
  "status": "success",
  "organization": "Bobby's Place",
  "branch": "All Branches",
  "count": 1,
  "products": [
    {
      "product_name": "Wireless Mouse",
      "product_code": "WM-001",
      "category": "Electronics",
      "brand": "Logitech",
      "branch": "HQ",
      "quantity": 15,
      "sale_price": 4500.0,
      "status": "Available"
    }
  ]
}
GET /api/v1/inventory/query/

Queries a specific product directly by its code or name.

Query Parameters (One of these is required):

  • code: Exact product code lookup (e.g. ?code=WM-001).
  • query: Loose name query search (e.g. ?query=Mouse).

Example Request:

curl -H "X-API-Key: qs_live_test_key_123456" \
     "http://localhost:8000/api/v1/inventory/query/?code=WM-001"

Response (200 OK):

{
  "status": "success",
  "organization": "Bobby's Place",
  "count": 1,
  "matches": [
    {
      "product_name": "Wireless Mouse",
      "product_code": "WM-001",
      "category": "Electronics",
      "brand": "Logitech",
      "branch": "HQ",
      "quantity": 15,
      "sale_price": 4500.0,
      "status": "Available",
      "reorder_level": 5
    }
  ]
}

WhatsApp Bot Integration Guide

Integrating with a WhatsApp API wrapper (like Twilio or Venom) is simple. When your server receives a webhook callback from WhatsApp with the text "is Wireless Mouse in stock?", follow this logic flow:

  1. Parse the message text to extract the product name query (e.g. Wireless Mouse).
  2. Send an HTTP request to the Quicksales Query API: 
    GET /api/v1/inventory/query/?query=Wireless+Mouse
  3. If the response contains matches with `quantity > 0`:
    • Reply to the user: Yes! "Wireless Mouse" is in stock. Quantity: 15. Price: ₦4,500.
  4. If `quantity <= 0`:
    • Reply: Sorry, "Wireless Mouse" is currently out of stock. We are restocking soon!
