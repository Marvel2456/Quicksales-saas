## Database Schema

### Coupon Table
```sql
CREATE TABLE subscriptions_coupon (
  id UUID PRIMARY KEY,
  code VARCHAR(50) UNIQUE NOT NULL,
  type VARCHAR(20) NOT NULL,
  value DECIMAL(10,2) NOT NULL,
  duration_days INT DEFAULT 30,
  max_uses INT DEFAULT 100,
  uses INT DEFAULT 0,
  start_date TIMESTAMP DEFAULT NOW(),
  end_date TIMESTAMP NULL,
  is_active BOOLEAN DEFAULT TRUE,
  created_at TIMESTAMP AUTO_ADD,
  updated_at TIMESTAMP AUTO_UPDATE
);
```

### CouponRedemption Table
```sql
CREATE TABLE subscriptions_couponredemption (
  id UUID PRIMARY KEY,
  coupon_id UUID REFERENCES subscriptions_coupon,
  organization_id UUID REFERENCES account_organization,
  subscription_id UUID REFERENCES subscriptions_subscription,
  used_at TIMESTAMP AUTO_ADD
);
```

### Payment Table (Modified)
```sql
ALTER TABLE subscriptions_payment
  ADD COLUMN coupon_id UUID REFERENCES subscriptions_coupon ON DELETE SET NULL;
```

## Support & Troubleshooting

### Common Issues

**Coupon not validating:**
- Check coupon code spelling (case handled automatically)
- Verify start_date/end_date validity
- Confirm is_active is checked
- Check max_uses not exceeded

**Wrong discount calculation:**
- Verify coupon type (percent/fixed/free)
- Check value is correct (10 = 10% for percent)
- Ensure decimal precision

**Payment not recording coupon:**
- Check init_payment received coupon_code
- Verify Payment created with coupon FK
- Check CouponRedemption was created

See **COUPON_API_REFERENCE.md** for detailed troubleshooting.
